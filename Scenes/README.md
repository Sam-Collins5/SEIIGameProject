# Description of all of our Scenes
    - battle_gfx.tscn
        > This is the player/enemy sprite scene for the aesthestics of the fight
    - battle_manager.tscn
        > Tracks player and enemy health, has all battle 
    - battle_ui.tscn
        > The UI for being inside of a battle in the game.
    - game_manager.tscn
        > Manages all moving between scenes, transitioning between title screen and game, enable and disable UI and scenes.
    - main_menu.tscn
        > Is the main menu when you start the game
    - player.tscn
        > The player code and sprites.
    - settings.tscn
        > The settings screen to change certain aspects about the game.
    - the_beginning.tscn
        > This is a test screen for running the prototype of the game.
